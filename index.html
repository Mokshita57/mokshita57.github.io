Where do online shoppers drop off?

E-commerce funnel analysis, October 2026

Using Google's public Google Analytics 4 data from its merchandise store, I wrote SQL in BigQuery to trace 270,000 visitors from product view to purchase, then split the funnel by device, traffic source and product category.

  • 7.2%of product viewers made a purchase.
  • 54.5%of shoppers who started checkout left without buying, the most valuable group to win back.
  • 7.5% vs 7.0%mobile and desktop converted about the same, so device is not the cause.
  • 4.8% vs 8.1%paid-ad visitors converted lowest; referral visitors converted best.
See the SQL behind the funnel 
WITH steps AS (
  SELECT
    COUNT(DISTINCT IF(event_name = 'view_item', user_pseudo_id, NULL))      AS viewed,
    COUNT(DISTINCT IF(event_name = 'add_to_cart', user_pseudo_id, NULL))    AS added_to_cart,
    COUNT(DISTINCT IF(event_name = 'begin_checkout', user_pseudo_id, NULL)) AS started_checkout,
    COUNT(DISTINCT IF(event_name = 'purchase', user_pseudo_id, NULL))       AS purchased
  FROM `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
)
SELECT
  viewed, added_to_cart, started_checkout, purchased,
  ROUND(100 * purchased / started_checkout, 1) AS pct_checkout_to_purchase,
  ROUND(100 * purchased / viewed, 1)           AS pct_overall
FROM steps;
